# Splearn 개발 가이드


## 아키텍처
- 헥사고날 아키텍처
- 도메인 모델 패턴

### 계층
- Domain Layer 
- Application Layer 
- Adapter Layer

>  외부(Actor) -> 어댑터 -> 애플리케이션 -> 도메인

## 패키지
- domain 
- application

  - provided : 애플리케이션이 제공하는 인터페이스 패키지
- adapter 
  - webapi 
  - persistence 
  - integration 
  - security
